# Changelog - FollowUpMod

## 0.1.0

- First version: adjusts a Roguelike co-op character to the party minimum level and grants the native skill, item and attribute rewards for each level gained.
- Characters above the party minimum stay refused, exactly as in the original game.
- The promoted level is session-only: the character file keeps the original level.
- Host publishes the party rule in the Steam lobby; a host without the mod keeps vanilla behaviour.
