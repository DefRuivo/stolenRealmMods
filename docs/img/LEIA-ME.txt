==========================================================
 CAPTURAS DE TELA PENDENTES — docs/img/
==========================================================

O README.md da raiz usa marcadores no formato
  ![descrição](docs/img/nome.png)
para os lugares onde uma captura de tela ajuda quem nunca
instalou um mod. Os arquivos abaixo AINDA NÃO EXISTEM — quem
for tirar as capturas deve salvá-las com EXATAMENTE estes
nomes, nesta pasta (docs/img/), senão as imagens aparecem
quebradas no GitHub.

Dica geral de captura (Windows):
  - Win + Shift + S = recorta uma área da tela e copia.
  - Cole no Paint e salve como PNG (não use JPG: o texto fica
    borrado e é justamente texto que a pessoa precisa ler).
  - Se quiser destacar um botão, desenhe um retângulo/balão
    vermelho em volta antes de salvar.
  - Prefira 1 captura por passo, largura ~1200px, e corte o
    excesso da tela (barra de tarefas, outros monitores).

7) manual-winhttp-na-pasta-do-jogo.png

   Usada em: instalação manual, passo 2.

8) logoutput-carregado.png
   Onde: Bloco de Notas (ou Notepad++) com

         Se o Bloco de Notas estiver em modo "quebra automática

9) ingame-tooltips-antes-depois.png
   Onde: no jogo, um tooltip de skill ou status aberto.

         que o BetterTooltips acrescenta no fim do tooltip.
         Para tirar o "antes": desmarque o BetterTooltips no
         r2modman, abra o jogo, capture, feche e religue o mod.
   Usada em: seção "Como saber que funcionou".

10) [OPCIONAL] ingame-fonte-serifada.png

----------------------------------------------------------
REGRAS PARA NÃO QUEBRAR O README
----------------------------------------------------------
- Nome do arquivo em minúsculas, sem acento e sem espaço.
- Se mudar o nome de um arquivo aqui, ATUALIZE o marcador
  correspondente no README.md da raiz.
- Se uma captura não puder ser tirada, é melhor REMOVER o
  marcador do README do que deixar imagem quebrada.
- NUNCA coloque arquivos de imagem dentro de BepInEx\plugins\
  nem na pasta do jogo: esta pasta docs/img/ é só do
  repositório (documentação).
